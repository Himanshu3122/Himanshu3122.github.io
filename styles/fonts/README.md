# Fonts

Latin-subset variable fonts, downloaded from Google Fonts and loaded with
`next/font/local` in `pages/_app.js`. Keeping them here means the build does
not depend on reaching Google's servers.

- Space Grotesk (weights 300–700), headings
- Inter (weights 100–900), body text
- JetBrains Mono (weights 300–500), code and labels

All three are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows bundling them with a website.
